# Component Map

## Responsibilities
Agents: execution roles.
Providers: model API adapters.
Plugins: reusable Workbench extensions.
Tools: controlled execution adapters.
Routing: Agent/model selection rules.
Evidence: structured execution records.
Benchmarks: repeatable measurements.
Workspaces: external research projects.
