## F. Capability truth

```text
Only a capability with an actual dated live observation may become VERIFIED.
```

No such observation was made, so at closeout every capability on every model
profile remains `UNKNOWN`:

| Model ref | tool_calling | structured_output | streaming | reasoning | prompt_caching |
| --- | --- | --- | --- | --- | --- |
| `deepseek/deepseek-flash` | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| `mimo/mimo-v2.6-pro` | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |
| `mimo/mimo-v2.6-flash` | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN | UNKNOWN |

B6 defined probes for `tool_calling` and `structured_output` and **declined** to
define any for the other three, because no safe, bounded, repeatable probe
exists in this phase:

- **streaming** — no shipped transport supports it, and `ProviderResponse`
  models no streamed chunks
- **reasoning** — a null result cannot distinguish "this model does not reason"
  from "this prompt did not trigger reasoning", so a probe would prove nothing
- **prompt_caching** — a cache hit requires a repeated prompt large enough to
  be cached, which contradicts the bounded low-cost prompt rule

B6's probe machinery can produce a *candidate* status for a human to review. It
**cannot modify a model profile** — that was verified — and nothing here
constitutes a promotion.

## H. Known limitations and deferred items

These are real, and none is an AI-02 failure.

1. **Actual provider connectivity remains `NOT_RUN`.** No live call was made.
   Confirming reachability, endpoint correctness, and API model ids is deferred
   until a credential is supplied and the live workflow is dispatched
   deliberately.
2. **`streaming`, `reasoning`, and `prompt_caching` remain `UNKNOWN`.** Each
   needs either transport work or a probe design this phase did not own.
3. **GitHub `main` branch protection remains `BLOCKED`** under the current
   GitHub Free / private-repository plan. Inherited from AI-00; unchanged, and
   not converted to `PASS`.
4. **Provider-declared endpoints and API model ids remain `DECLARED`.** They are
   unverified until a dated observation exists.
5. **Pricing ships no price.** The default catalog is empty; `estimated_cost`
   is `null` until a dated pricing record is supplied.
